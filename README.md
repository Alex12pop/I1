## Примеры кода
Пример реализации интерактивной анкеты студента, совмещающей ввод данных, конвертацию типов, вычисления и интерполяцию строк:

```csharp
using System;

Console.WriteLine("Добро пожаловать в анкету!");

Console.Write("Введите ваше имя: ");
string name = Console.ReadLine();

Console.Write("Введите ваш год рождения: ");
int birthYear = int.Parse(Console.ReadLine());

Console.Write("Введите ваш средний балл: ");
double gpa = double.Parse(Console.ReadLine());

int currentYear = 2026;
int age = currentYear - birthYear;
string status = gpa >= 4.5 ? "Отличник" : "Хорошист";

Console.WriteLine("\nВаша анкета");
Console.WriteLine(\$"Имя: {name}");
Console.WriteLine(\$"Возраст: {age} лет");
Console.WriteLine(\$"Статус: {status}");
```

## Ответы на контрольные вопросы

1. **Чем `Console.Write()` отличается от `Console.WriteLine()`?**
   * `Console.Write()` выводит указанный текст в консоль, оставляя курсор на той же строке для последующего ввода или вывода.
   * `Console.WriteLine()` выводит текст и автоматически осуществляет перевод курсора на следующую строку.

2. **Что произойдёт, если попытаться присвоить переменной типа `int` значение `3.14`?**
   * Произойдет ошибка компиляции (синтаксическая ошибка типа *CS0266*), так как в C# применяется строгая статическая типизация. Неявное приведение вещественного типа `double` к целочисленному `int` с потерей точности запрещено.

3. **Почему `10 / 3` в C# даёт `3`, а не `3.333...`? Как получить дробный результат?**
   * В C# операция деления над двумя целочисленными операндами (`int`) всегда выполняется как целочисленная, отбрасывая остаток.
   * Чтобы получить дробный результат, необходимо хотя бы один из операндов явно или неявно привести к вещественному типу (например, написать `10.0 / 3` или `(double)10 / 3`).

4. **Что означает `var` в C#? Чем он отличается от динамической типизации в Python?**
   * Ключевое слово `var` включает автоматический вывод типа компилятором на основе присваиваемого значения прямо во время сборки.
   * В отличие от Python, где типизация динамическая и переменная может свободно менять свой тип в процессе выполнения кода, в C# переменная с ключевым словом `var` получает строгий неизменяемый тип один раз при объявлении.

5. **На каких крупных проектах или компаниях используется C# и .NET?**
   * **Microsoft:** Огромная часть экосистемы (включая облако Azure, внутренние Windows-компоненты и Xbox-сервисы) работает на .NET.
   * **Stack Overflow:** Вся серверная архитектура одного из крупнейших сайтов для разработчиков исторически построена на базе C# и ASP.NET.
   * **Unity Technologies:** C# является основным языком программирования в популярном игровом движке Unity, на котором созданы тысячи известных игр (например, *Hollow Knight*, *Genshin Impact*, *Subnautica*).
